# 🚀 Enamel-2 Dental Website - Quick Start Guide

## ✅ Everything is Ready!

### To Start the Development Server:

```bash
npm run dev
```

Then open: **http://localhost:3000**

## 🔧 If You See Errors:

1. Stop the server (Ctrl+C)
2. Clear cache: `Remove-Item -Recurse -Force .next`
3. Rebuild: `npm run build`
4. Start again: `npm run dev`

---

## 📝 To Edit Content:

All content is in: `/config/client.ts`

You can change:

- Clinic name, doctor name
- Phone numbers
- Services offered
- Reviews
- Hours, address
